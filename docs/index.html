The Art Director is a stripped-down Design Mode: a browser overlay where you point, move, measure and comment on a live page. Each change goes to Claude Code as a precise instruction and ships as token-correct CSS. You never set a hex value or a type scale.

Download the extension Chrome / Edge / Brave / Arc · unzip and "Load unpacked"

The idea

A director's instrument

Design Mode is a full design app developed by Sandeep Baskaran, with controls for type, colour, effects and tokens. We took it and removed the controls that set a style value. What is left is the handful a director reaches for on a live page: point, move, space, measure, comment.

The styling goes to Claude Code. You point and judge; the coding agent writes the CSS. You keep the taste and the decision.

How it works

  1. Open the panel on a live page: localhost, staging or production.
  2. Point. Drag to move, use the handles to resize, measure the distance between two things.
  3. Say it in words where a value is not the point: pin a comment on that exact element.
  4. Show motion when you want an interaction across: hover, appear, scroll.
  5. Copy Prompt. Everything collects in the Changes log and goes to Claude Code as a precise diff.
  6. Claude builds it in token-correct CSS, in the real codebase.

The discipline

What stays, what goes

Stays

  • →Point, move, resize, measure
  • →Spacing and reordering sections
  • →Comments on an element
  • →Quick text rewrites
  • →Motion interactions
  • →Changes log, Copy Prompt, MCP handoff

Goes

  • ×Type, colour and fill controls
  • ×Border, corner, effects, transform
  • ×The tokens panel and loose CSS fields
  • ×Motion longhand and the export formats

Token awareness still runs under the hood, so the diff to Claude stays token-correct. You just no longer set it by hand.

Install

In two minutes

  1. Download the extension above and unzip it.
  2. In Chrome, open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin the icon, open a page, click Art Director. The side panel opens.

The automatic handoff to your agent runs over a small local MCP server. Without it, "Copy Prompt" still works: you paste the diff into your agent.
